# Forge 2.0 — Implementation Roadmap

> **Spec:** [`docs/superpowers/specs/2026-08-12-forge-2.0-design.md`](../specs/2026-08-12-forge-2.0-design.md)

Forge 2.0 is five independently shippable plans. Each produces working, testable software. Do not start plan *N+1* until plan *N* is merged and green (`./build.sh --skip-install` → `./test.sh`).

| # | Plan | Status | Delivers |
|---|------|--------|----------|
| 1 | [`2026-08-12-forge-2.0-forgefile.md`](./2026-08-12-forge-2.0-forgefile.md) | **Ready** | Required Forgefile parse/validate, DB projection + pickup, deployer/Ops/UI gated on it, docs + annotated template, “create with agent” CTA |
| 2 | [`2026-08-12-forge-2.0-service-directory.md`](./2026-08-12-forge-2.0-service-directory.md) | **Ready** | Service directory, basic health monitoring, Caddy route scaffolding |
| 3 | [`2026-08-12-forge-2.0-artifacts.md`](./2026-08-12-forge-2.0-artifacts.md) | **Ready** | Artifact declare/build/store/download (disk driver; S3-shaped API) |
| 4 | [`2026-08-12-forge-2.0-agent-containers.md`](./2026-08-12-forge-2.0-agent-containers.md) | **Ready** | Per-session agent containers, heartbeat/idle/wall-clock kill, hybrid secrets, Ops-only |
| 5 | [`2026-08-12-forge-2.0-git-server.md`](./2026-08-12-forge-2.0-git-server.md) | **Ready** | Forge primary git (HTTP+SSH), UI create project, GitHub one-shot import |

**Interim (plans 1–4):** projects may still clone from GitHub; **Forgefile is still required**. Plan 5 switches origin to Forge.

**Global constraints (all plans):**

- Never run Forge’s own `./deploy.sh` from agents; use Ops/UI Redeploy
- Verify with `./build.sh --skip-install` and `./test.sh` before finishing a plan
- Agents: no Docker socket (plan 4); until then keep today’s in-process agent but Forgefile bootstrap CTA works
- Spec decisions stay locked unless the human revises the design doc
