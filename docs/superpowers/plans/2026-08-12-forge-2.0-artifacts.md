# Forge 2.0 Plan 3 — Artifacts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Forgefile-declared file artifacts as Forge privileged jobs, store them on disk behind an S3-shaped storage interface, and distribute via authenticated Ops/UI download.

**Architecture:** Project artifact declarations from Forgefile into `artifacts`. `buildArtifact` checks out the branch, runs the declared build command via `runForgeCommand`, stores the output path through `ArtifactStorage`. Retention keeps last N builds. Image release JSON pins remain separate (`deploy-rollback.ts`).

**Tech Stack:** TypeScript, Vitest, SQLite/Drizzle, `forgefile-run.ts`, Node fs, Next.js App Router.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-12-forge-2.0-design.md`
- Requires Plan 1 (valid Forgefile + `runForgeCommand`)
- Storage root: `{dirname(FORGE_DB_PATH)|/data}/artifacts/{projectId}/{name}/{buildId}/`
- Driver interface must allow future S3 without API break: `put`, `get`, `delete`, `signedDownload`
- Retention default N=10; manual delete supported
- Failed builds: row with error; no download
- Auth required for download (dashboard session or Ops token)
- `./build.sh --skip-install` + `./test.sh` before finish

### Task 2: Disk storage driver

**Interfaces:**
```ts
export type ArtifactStorage = {
  put(key: string, localFilePath: string): Promise<{ sizeBytes: number }>;
  get(key: string): Promise<{ absolutePath: string } | null>;
  delete(key: string): Promise<void>;
  signedDownload(key: string, expiresSec: number): Promise<{ urlPath: string; token: string; expiresAt: Date }>;
};
export function createDiskArtifactStorage(rootDir: string): ArtifactStorage;
export function resolveArtifactsRoot(): string;
```
- `signedDownload` for disk: HMAC token query param verified by download route (same secret pattern as ops session secret or dedicated `FORGE_ARTIFACT_DOWNLOAD_SECRET`)

- [ ] Tests with temp dir put/get/delete/sign
- [ ] Implement → commit `feat(artifacts): add disk artifact storage driver`
